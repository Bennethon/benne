# benne.games

The BENNE documentation site, built with [VitePress](https://vitepress.dev/) and served from Cloudflare Workers static assets.

- `guide/`: the user guides.
- `reference/bennescript-api.md`: includes the `site` region of `docs/bennescript-api.md`. The reference half of that file is generated by `npm run docs:api` at the repo root, so edit the JSDoc in the engine, not this page.
- `index.md` and `.vitepress/theme/`: the homepage and theme. The B and the first N in BENNE come from `.vitepress/theme/bWords.ts` and `nWords.ts`.
- `public/`: static files, served from the site root.

Heading anchors follow GitHub's style (see `markdown.anchor` in `.vitepress/config.ts`), so `#anchor` links work both on GitHub and on the site.

## Develop

```bash
npm ci          # in website/
npm run dev     # or `npm run site:dev` from the repo root
npm run build   # fails on dead links
npm run preview
```

## The homepage game

The homepage monitor plays whatever is in `public/play/`. It shows a "coming soon" screen until `public/play/index.html` exists. The intro game is a separate BENNE project. To update it here, run `npm run build:itch` in the game's project, unzip the result into `public/play/` and commit it.

Workers static assets refuse files over 25 MiB, so keep every file in the build under that. Video registers at boot but only streams when it plays, so the tutorial recording on the game's computer (about 19 MB) is fine here. Audio is downloaded before the game starts, so encode music as MP3 rather than WAV. A video that outgrows the limit belongs on Cloudflare Stream or R2.

## Deploy

`wrangler.jsonc` serves `.vitepress/dist` as the `benne-games` Worker on the `benne.games` custom domain.

- **Automatic:** in the Cloudflare dashboard, go to Workers & Pages → Create → Import a repository. Pick `Bennethon/benne`, branch `master`, root directory `website`, build command `npm ci && npm run build`, deploy command `npx wrangler deploy`. Pushes to master then deploy, and other branches get preview URLs.
- **By hand:** `npx wrangler login`, then `npm run deploy`.
- **www:** add a proxied DNS record for `www` and a Redirect Rule from `www.benne.games/*` to `https://benne.games/${1}` (301).
