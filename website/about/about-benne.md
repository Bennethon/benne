# About BENNE

BENNE (Bennethon Engine for Nifty Narrative Experiences) is a web-based engine and VS Code editor for making point-and-click adventure games. You build rooms, characters, inventory, dialogs and interfaces in the BENNE Editor, write the game logic in BenneScript, and ship the result to the web or the desktop. It takes its lead from Adventure Game Studio and the classic LucasArts and Sierra adventures, and is a personal project, released as open source under the [MIT License](/about/license).

## Built with

- **[TypeScript](https://www.typescriptlang.org)**: the engine, the editor and BenneScript itself.
- **[Phaser 4](https://phaser.io)**: rendering, animation, input and audio in the browser.
- **[Vite](https://vite.dev)**: the development server and game builds.
- **[VS Code extension API](https://code.visualstudio.com/api)**: the BENNE Editor, bundled with [webpack](https://webpack.js.org).
- **[Cytoscape.js](https://js.cytoscape.org)** and **[ELK](https://eclipse.dev/elk/)**: the editor's puzzle dependency charts.
- **[Electron](https://www.electronjs.org)** and **[electron-builder](https://www.electron.build)**: desktop builds of games.
- **[Aseprite](https://www.aseprite.org)**: the art pipeline for sprites and animations.
- **[Vitest](https://vitest.dev)** and **[Playwright](https://playwright.dev)**: unit and end-to-end tests.
- **[VitePress](https://vitepress.dev)**: this website.
